# Inventory

* **Switch between primary weapons:** `1`
* **Switch between secondary weapons:** `2`
* **Switch between melees:** `3`
* **Switch between projectiles:** `4`

# Weapons

* **Shoot:** `LMB`
* **Remove silencer:** `RMB`
* **Reload:** `R`

# Projectiles

* **Throw:** `LMB`
* **Hold pin:** `Hold LMB`
* **Cancel:** `Switch to any weapon`

# Movement

* **Walk:** `Shift`
* **Crouch:** `Ctrl`
* **Move:** `WASD`
* **Jump:** `Space`

# Misc

* **Radio:** `G` (feature removed)
* **Mirror viewmodel:** `H`

# Debug

* **Debug menu:** `F8`
